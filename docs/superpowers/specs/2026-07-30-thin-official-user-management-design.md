# Official Site Portal 薄账户管理设计

## 目标

Official Site Portal 仅提供演示所需的最小账户管理能力：

- 查询账户列表；
- 新增账户；
- 删除账户；
- 重置账户密码。

不提供账户信息编辑、启用或禁用能力。

## 组件与接口

SSO Login Demo 继续持有账户数据，并提供：

- `GET /api/ops/users`：查询账户；
- `POST /api/ops/users`：新增账户；
- `DELETE /api/ops/users/{id}`：删除账户；
- `POST /api/ops/users/{id}/reset-password`：重置密码。

Official Site Portal 只代理这些接口，并在运维页面提供对应操作。删除操作需要用户确认。

## 删除语义

删除为硬删除。删除成功后，该账户不能继续发起新的登录。已经签发的短期登录结果按现有过期机制结束，不增加额外撤销链路。

Cloud 已保存的外部身份映射不随账户删除而级联删除。映射由 Cloud 管理，SSO Login Demo 不跨系统删除 Cloud 数据。重新创建同名账户会获得新的内部身份，并在首次登录时形成新的映射。

## 安全与响应

账户新增、删除和密码重置响应均不得包含密码、密码哈希或登录凭证。删除不存在的账户返回未找到；账户 ID 不变更也不复用。

## 验证

- SSO Login Demo 接口测试覆盖新增、删除、删除后无法登录、密码重置和敏感数据不输出；
- Site Portal 代理测试覆盖删除请求；
- 全量 Go 测试通过；
- Demo 侧验证新增账户可以登录，删除后不能登录，页面不存在启用或禁用入口。
