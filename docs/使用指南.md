# 飞印使用指南

本说明书说明飞印日常使用涉及的三个界面：管理网站、一体机大屏、一体机本机设置。正文按上述顺序编排。服务器安装、域名变更、校区日常开关机等事项由交付方另行说明，不纳入本册。

一体机本机设置不设独立登录密码，依赖物理可达性进行管理，不得将该页面故意暴露至公网。

---

## 1. 管理网站

管理网站使用浏览器打开，地址由交付方提供（常见形式为 `…/fly-print-web/login`）。

【插图 1｜管理网站登录页｜截取登录页全貌，密码可打码】

首次登录账号一般为 `admin`；初始密码由交付方通过受控交付材料或值班人员提供。登录成功后应尽快修改密码。

### 1.1 开通一体机（激活）

用于新一体机首次接入云端。

【插图 2｜激活｜拼图：①「节点信息」创建待激活终端并显示激活码；② 节点列表中该节点为在线（一体机侧填写见第 3 章）】

1. 打开「节点信息」，选择创建待激活终端，获取一次性激活码。  
2. 激活码具有时效，使用后即失效；超时须重新生成。  
3. 将激活码交由现场在一体机本机设置中完成激活（见第 3 章）。  
4. 激活成功后，在「节点信息」中确认该节点状态为在线。  

激活码不得在公开渠道传播。

### 1.2 查询任务与核对打印机

打印任务可在「打印任务」中按节点、打印机或状态查询，用于追溯进度与失败原因。  
「打印机信息」用于核对一体机上报的打印机登记情况，并可修改显示名、启停或删除。日常添加打印机、设置默认机以一体机本机设置为准（见第 3 章）。

【插图 3｜打印任务与打印机信息｜各截取一页有代表性的列表】

### 1.3 第三方入口（可选）

若扫码入口页需展示第三方业务名称，须在「三方接入」中完成配置，并满足：该接入已启用，且「入口显示」已打开。用户侧操作见第 2 章。

密钥创建或轮换时仅明文展示一次，须妥善保存。

【插图 4｜三方接入｜已启用且入口显示打开的配置页；密钥区域勿入图】

### 1.4 页面说明

【插图 5｜管理网站侧栏｜登录后含左侧菜单的整页，敏感数据可打码】

| 页面 | 功能说明 |
|------|----------|
| 总览 / 仪表盘 | 查看节点、打印机概况与告警 |
| 节点信息 | 创建待激活终端；查看在线状态；修改名称或别名；启停或删除节点 |
| 运维人员 | 维护姓名与电话，并绑定至节点（可在一体机大屏底部展示） |
| 打印机信息 | 修改显示名、启停、删除；按节点筛选；跳转相关任务 |
| 打印任务 | 按条件查询历史任务及失败原因 |
| 业务配置 | 上传大小、页数、允许的文件类型、凭证有效期等（变更影响全局，须慎重） |
| 三方接入 | 配置入口与回调、启停与入口是否显示、密钥轮换 |

手机端官方上传页由扫码流程自动打开，无需管理员登录，亦不出现在侧栏菜单中。

## 2. 一体机大屏

一体机开机后进入全屏界面，用于出示二维码、预览与确认打印。

### 2.1 官方扫码打印

此为最高频业务流程。

【插图 6｜官方扫码打印｜按序拼图：① 大屏出码；② 手机入口选「飞印官方打印」；③ 手机上传页；④ 一体机预览；⑤ 完成页；每格短标题】

1. 大屏处于待机状态并显示二维码。  
2. 使用手机扫描二维码，打开打印入口页。  
3. 选择「飞印官方打印」。若入口页仅有一个按钮，直接选择即可。  
4. 在手机端按页面提示上传文件。允许的类型、大小与页数以上传页提示为准（常见为 PDF；不符时将上传失败）。  
5. 在一体机预览页确认份数、单双面、黑白或彩色等参数。灰色选项表示当前打印机不支持。  
6. 选择「立刻打印」，等待打印过程结束。  
7. 完成后取件，并可返回待机。  

注意事项：

- 用户进入流程后，大屏可能遮挡二维码，表示本机占用中；他人使用完毕或现场刷新后，方可重新出码。  
- 打印进行中不得返回扫码页。  
- 二维码具有时效；失效后须在一体机刷新后再扫。  
- 缺纸、缺粉、卡纸时，按屏幕提示处理并检查打印机。

【插图 7｜占用与刷新｜占用中画面 + 刷新后重新出码各一张】

### 2.2 第三方入口打印（可选）

前提：管理网站「三方接入」中相应入口已启用，且入口显示已打开。

【插图 8｜入口页多按钮｜手机入口页同时展示「飞印官方打印」与第三方名称】

扫描二维码后选择第三方名称，按对方页面完成选文件与提交，再返回一体机预览并确认打印。第三方页面的具体操作以对方说明为准；飞印侧须在一体机确认后才会出纸。

### 2.3 画面说明

【插图 9｜大屏主要画面｜拼图标注：待机出码、故障或未就绪、使用中、预览、打印中、完成或失败】

| 画面 | 说明 |
|------|------|
| 待机出码 | 可扫码；可能定时自动更换二维码；可手动刷新 |
| 故障 / 未就绪 | 未激活、打印机异常或云端不可用等；二维码被遮挡，须由工作人员处理 |
| 使用中 | 已有用户进入流程；可刷新以回收会话并重新出码 |
| 预览 | 调整打印参数并确认或返回 |
| 打印中 | 正在处理，请等待 |
| 完成 / 失败 | 成功后可返回待机；失败时按提示检查打印机或联系运维 |

## 3. 一体机本机设置

在一体机本机浏览器访问：`http://127.0.0.1:7860/admin`（通常仅本机可访问）。

【插图 10｜本机设置总览｜整页截图，标注：激活、云端连接、打印机管理、打印设置、应用设置】

### 3.1 填写云端地址并激活

配合第 1 章在管理网站生成的激活码使用。

1. 填写交付方给定的云端地址（须与手机可访问的地址一致；若含路径前缀，不得遗漏）。  
2. 填写激活码并完成激活。  
3. 确认云端连接状态为已连接。  
4. 返回管理网站「节点信息」，确认该节点为在线。

### 3.2 添加打印机并设为默认

【插图 11｜打印机管理｜列表页，标出「刷新」「设为默认」「测试打印」】

1. 打开「打印机管理」，优先使用「刷新」发现打印机（一体机与打印机须处于同一网络，且打印机已开机）。  
2. 若仍无法发现，按现场提供的地址手动添加后再检测。  
3. 选定目标打印机，设为默认。  
4. 建议执行「测试打印」以确认可出纸。  

未设置默认打印机时，用户往往无法完成扫码打印。变更默认机后，宜再完成一次官方扫码打印验证。

### 3.3 分区说明

| 分区 | 功能说明 |
|------|----------|
| 激活（未激活时） | 填写云端地址与激活码并激活 |
| 云端连接 | 查看连接状态；修改节点名称、位置等；保存配置；必要时解除本机绑定（须慎重） |
| 打印机管理 | 发现或添加打印机、设为默认、测试打印、删除 |
| 打印设置 | 默认纸张、份数上下限等（装机或排障时调整） |
| 应用设置 | 如开机自启并打开用户大屏（按交付要求勾选） |

本机设置通常不提供「日志」菜单；深入排障由运维查阅本机日志文件。

## 4. 常见情况对照

| 现象 | 处理建议 |
|------|----------|
| 扫码提示过期或无效 | 在一体机刷新二维码后重新扫描 |
| 管理网站登录失败 | 核对地址与账号密码来源；仍失败时联系云端值班 |
| 节点长期离线 | 检查一体机网络、云端地址是否正确、是否已完成激活 |
| 有预览但无法出纸 | 检查默认打印机、纸张与耗材，并执行测试打印 |
| 他人正在使用导致无法扫码 | 等待对方完成，或现场刷新二维码以回收会话 |
| 入口页无第三方选项 | 在「三方接入」中确认已启用且入口显示已打开 |
| 刷新后仍发现不到打印机 | 确认同网且打印机已开机；仍无结果时按地址手动添加 |
