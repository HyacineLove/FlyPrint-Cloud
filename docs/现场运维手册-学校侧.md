## 1. 系统长什么样（先看懂再动手）

飞印分成两块：

- **云端（Cloud）**：在公网上，由上级单位维护。学校**不用管服务器**。
- **一体机（Edge）**：放在本校区，负责出示二维码、让用户确认、把文件打到打印机。

```text
手机扫码 ──► 公网云端 ──► 本校一体机 ──► 本校打印机
```

**【插图 1：整体关系】**  
建议截：手机 + 一体机屏幕 + 打印机的现场合影，或手绘「手机→云→一体机→打印机」四格示意。

**学校要管的：** 一体机是否开机、能否出码、打印机有纸有墨、网络能否上网。  
**学校不用管的：** 云服务器、数据库、网站后台服务器本身。

## 2. 开业前要准备什么

| 准备项 | 说明 |
|--------|------|
| 一体机 1 台 | Windows，能稳定开机；已安装飞印 Edge |
| 打印机 1 台起 | 与一体机在同一网络，能被一体机发现（IPP） |
| 能上网 | 一体机可访问公网云端（浏览器能打开管理端网站即可作粗测） |
| 现场责任人 | 每校区一名（可兼职） |
| 交接材料 | 云端地址、激活方式、管理员联系人（由交付方提供） |

两校区 = 上述准备 **×2**；云端仍是同一套，不用学校再买服务器。

## 3. 每天怎么做（日常）

### 3.1 上班开机

1. 打开一体机电源，等待进入飞印界面（全屏二维码或待机页）。  
2. 确认屏幕上**能看到二维码**（或明确的「准备就绪」状态）。  
3. 看打印机：开机、有纸、无缺墨/卡纸红灯。

**【插图 3：一体机正常待机（有二维码）】**  
建议截：Edge 用户界面正常出码画面。

### 3.2 下班（按学校规定）

- 可关机或锁屏休眠（以交付方现场交代为准）。  
- 不要随意卸载软件、不要随便改「云端地址」。

### 3.3 每周简单看一眼

- 一体机时间是否正确（时间错了可能导致证书/登录异常，虽当前为 HTTP 也建议校准）。  
- 打印机耗材是否充足。  
- 用自己手机扫一次码，确认能打开打印入口页面（不必每次真打）。

## 4. 常见问题怎么处理（先自己看，再报障）

### 4.1 屏幕没有二维码 / 提示离线

1. 检查一体机是否联网（能否打开任意网页）。  
2. 重启一体机，等待 2～3 分钟再看是否恢复出码。  
3. 仍不行 → 联系云端值班，说明**校区、一体机位置、大概故障时间**。

**【插图 4：离线或故障遮挡画面】**  
建议截：无码 / 离线 / 占用遮挡时的屏幕。

### 4.2 手机扫码打不开或 404

1. 确认手机网络正常。  
2. 看地址是否类似：`…/fly-print-api/entry…`（不要只打开网站首页就当打印入口）。  
3. 让一体机**刷新二维码**后再扫。  
4. 仍不行 → 把手机地址栏**完整网址**拍照发给值班。

### 4.3 能上传但打不出来

1. 看一体机是否停在预览页等待确认。  
2. 看打印机是否缺纸、缺粉、卡纸、休眠。  
3. 在一体机管理页确认默认打印机仍在（需会进管理页的人员操作；不会则直接报障）。  
4. 仍不行 → 报障，并说明「有预览 / 无出纸」还是「完全无预览」。

### 4.4 别人正在用，自己扫不了

正常现象：一台一体机同一时间只服务一笔进门会话。等对方完成或现场刷新二维码后再试。

## 5. 什么情况必须联系云端值班

| 情况 | 学校侧先做 | 然后 |
|------|------------|------|
| 连续离线超过约 15 分钟 | 查网、重启一体机 | 报障 |
| 管理员网站无法登录（外网） | 换网络再试 | 报障并附截图 |
| 升级通知 | 按通知时间窗口操作 | 升级失败立即报障 |
| 怀疑中毒 / 误删软件 | 停用该机 | 立即报障，勿自行重装乱试 |

报障请尽量带齐：**校区、时间、现象、手机网址截图、一体机屏幕截图**。

## 6. 升级一体机软件（按通知做）

1. 收到升级通知（版本号、安装包、时间窗口）。  
2. 确认当时**没有人正在打印**。  
3. 按通知安装 / 覆盖安装。  
4. 安装后检查：能出码；云端地址未被改乱；打一页测试页（如通知要求）。  
5. **不要**自行改云端地址，除非通知写明新地址。

建议截：本机管理页里 `cloud.base_url` 配置处（可打码激活信息）。

## 7. 两校区怎么分工

| 谁 | 做什么 |
|----|--------|
| 各校区现场责任人 | 本校一体机与打印机日常、一级报障 |
| 云端维护方 | 公网 Cloud、域名、证书、账号体系、发升级包 |
| 学校信息化（如有） | 校内防火墙放行访问云端；协助提供 Edge 出口公网 IP（若需白名单） |

两校区互不影响出纸：一台坏了，另一校区仍可打；都连同一套云端。

**【插图 7：两校区示意】**  
建议手绘或幻灯：云端居中，校区 A / 校区 B 各一台一体机 + 打印机。

---

## 8. 不要做的事

- 不要执行任何「清空服务器数据」类操作（交付方也不会对学校要求这个）。  
- 不要卸载飞印、不要安装来路不明的「优化」软件。  
- 不要把一体机管理页故意暴露到公网。  
- 不要把 Admin 密码、Demo 密码发到公开群。
